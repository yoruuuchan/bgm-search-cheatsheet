# BGM 搜索关键词速查表

> 免费曲库（Pixabay / Mixkit / YouTube Audio Library 等）的搜索黑话对照表。
> 核心原则：**曲库标签标的是"感觉"，不是"用途"** —— 搜 `background music` 出来的是电子垃圾，搜 `soft ambient underscore` 出来的才是能用的铺底。

## 怎么用这张表

搜索串 = **场景词 + 情绪词 + 质感词**，三段拼积木：

```
documentary + calm + piano        → 纪录片 · 平静 · 钢琴
corporate  + hopeful + ambient    → 宣传片 · 有希望感 · 氛围垫
epic       + rising  + orchestral → 大场面 · 情绪爬升 · 管弦
```

先从下面 20 个场景里找到你的视频类型，复制现成搜索串；不对味就去横向词库换零件。全站搜索一律用**英文**。

## 一、20 个视频场景

### 1. 采访 / 人物访谈铺底

说话为主的视频，音乐的美德是"存在但不被注意"。

```
documentary underscore calm
soft ambient bed
minimal piano underscore
warm atmosphere interview
```

- 认准 **underscore**（垫乐）——行业术语，专指垫在说话底下的配乐，纪录片圈用词
- 选低频厚、中频干净的曲子：人声集中在 250–2500Hz，好的铺底会主动避开这个频段
- 避开：忽大忽小的动态、突然的乐器 solo、明显的旋律钩子（会抢话）
- **慎选钢琴独奏**：钢琴主旋律音区恰好和人声完全重叠，"soft piano" 听着温柔，垫在采访底下反而糊（实测一批候选里垫底的多数是钢琴曲）；pad / 氛围垫类安全得多

### 2. 企业 / 机构宣传片

官方感、专业、积极向上，但不能俗。

```
corporate uplifting
corporate ambient inspiring
motivational corporate piano
business success background
```

- **corporate** 是曲库最大的类目之一，温暖钢琴 + 弦乐 + 轻节拍是标配
- 要更有格调就加 `minimal` 或 `cinematic`，去掉土味

### 3. 科技 / AI / 产品展示

未来感、精密感、干净。

```
technology innovation ambient
futuristic minimal electronic
digital tech corporate
science discovery atmosphere
```

- 质感词用 `synth` `pulse` `glitch`（电子脉冲感）或 `clean` `minimal`（苹果风）
- 严肃科研向加 `documentary`，发布会向加 `uplifting`

### 4. 纪录片 / 叙事

有时间跨度、有故事线的片子。

```
documentary storytelling
cinematic narrative underscore
emotional documentary strings
history documentary orchestral
```

- **storytelling / narrative** 这两个词能筛出"有起承转合"的曲子
- 自然风光纪录片加 `earth` `nature` `wildlife`

### 5. 情感 / 治愈 / 催泪点

人物故事的高潮段、回忆杀、结尾升华。

```
emotional piano touching
heartwarming strings
nostalgic sentimental piano
hopeful emotional cinematic
```

- **touching / heartwarming / nostalgic** 是三个精确度极高的情绪词
- 钢琴独奏搜 `solo piano`，加弦乐铺垫搜 `piano strings`

### 6. Vlog / 日常生活

轻松、有节奏感、跟着走就行。

```
vlog upbeat acoustic
happy ukulele whistle
chill vlog groove
morning routine acoustic
```

- 阳光款认准 `acoustic` `ukulele` `whistle`（口哨）`clapping`（拍手）
- 城市感/时髦感换 `groove` `funky` `jazzy`

### 7. 旅拍 / 风光 / 航拍大景

开阔、呼吸感、镜头一拉就起飞。

```
cinematic travel inspiring
aerial epic atmosphere
wanderlust adventure cinematic
sunrise majestic orchestral
```

- **wanderlust**（旅行渴望）是旅拍专属高质量标签
- 航拍大景要 `epic` `majestic` `soaring`（翱翔感）

### 8. 运动 / 高能剪辑 / FPV 冲刺

卡点、肾上腺素、速度感。

```
energetic sport rock
powerful drive electronic
extreme action drum and bass
phonk drift
```

- FPV 穿越机圈当下流行 **phonk**（记住这个词）
- 卡点剪辑选 `drum and bass` `trap` `dubstep`，鼓点清晰好卡
- `driving`（推进感）是筛节奏的好词

### 9. 史诗开场 / 预告片式

大场面、正片开始前的那口气。

```
epic trailer orchestral
cinematic intro powerful
epic rising tension drums
heroic orchestral brass
```

- **trailer** 一词直接命中预告片结构（爬升→爆发）
- `rising` `building` 表示情绪逐步堆叠，适合配蒙太奇

### 10. 悬念 / 紧张 / 揭晓前

转场、设问、答案揭晓前的停顿。

```
suspense tension minimal
dark mysterious ambient
investigation pulse
dramatic tension strings
```

- `pulse`（脉冲底鼓）+ `minimal` 是纪录片式悬念的标配
- 不要真恐怖就避开 `horror` `creepy`

### 11. 欢快活动 / 花絮 / 快闪

团建、活动记录、NG 花絮、轻喜剧。

```
fun playful quirky
happy swing jazz
comedy pizzicato
celebration party pop
```

- **quirky**（俏皮古怪）和 **pizzicato**（弦乐拨奏）是花絮/喜剧的秘密武器

### 12. Lo-fi / 学习陪伴 / 轻松长视频

教程、直播垫乐、长时间不烦。

```
lofi chill beat
study beats calm
lofi hip hop relaxed
cozy jazz cafe
```

- 教程解说建议 lo-fi 而非纯 ambient：一点节拍能撑住节奏又不抢话

### 13. 开箱 / 产品测评

干净、现代、有点酷，但不抢产品风头。

```
modern product showcase
minimal pop upbeat
stylish tech groove
sleek commercial background
```

- 测评类音乐的要点是"干净不抢戏"：`minimal` + `pop`/`house` 轻律动最稳
- 产品特写慢镜头配 `sleek` `stylish` `elegant`，参数罗列段配轻 `tech`

### 14. 美食 / 探店 / 厨房

烟火气或咖啡香，二选一。

```
cooking food jazz
bossa nova cafe
kitchen fun acoustic
food vlog funky
```

- 西餐 / 咖啡 / 烘焙认准 **bossa nova** 和 `cafe jazz`；中餐 / 市井烟火用 `playful acoustic` 更对味
- 快节奏切菜卡点段换 `funky` `swing`，鼓点和刀工对齐

### 15. 时尚 / 美妆 / 高级感

秀场律动，或者留白的高级。

```
fashion stylish house
chic lounge groove
luxury elegant ambient
catwalk deep house
```

- **fashion** + **house** 是秀场标配四四拍；`chic` `elegant` 出高级感
- 高级感的关键是做减法：选 `minimal` `deep`，音符越少越贵

### 16. 婚礼 / 浪漫 / 纪念日

仪式感和眼泪，都要克制。

```
wedding romantic piano
love story emotional strings
romantic acoustic guitar
first dance ballad
```

- 仪式环节用 `piano strings` 慢板；first dance 搜 `ballad` `slow dance`
- 一定加 `instrumental` 排除人声，除非你就是要某首特定的歌

### 17. 游戏 / 电竞 / 直播

从像素怀旧到赛场高光。

```
gaming energetic electronic
esports trap hype
chiptune 8-bit retro game
synthwave gaming night
```

- 高能集锦用 `trap` `dubstep`；像素 / 复古游戏内容认准 **chiptune** `8-bit`
- 长时间直播垫乐回场景 12 的 lo-fi，观众的耳朵会谢你

### 18. 复古 / 80s / 胶片怀旧

两种复古别搞混：霓虹复古未来 vs 真的老。

```
synthwave retrowave 80s
retro funk disco
vintage jazz oldies
nostalgic tape cassette
```

- **synthwave / retrowave** 是"80 年代人想象的未来"（霓虹、夜景、赛博）；`vintage` `oldies` 是"真·老歌质感"
- 胶片 / CCD 画面配带 `tape` `vinyl` 底噪的曲子，质感统一

### 19. 冥想 / 瑜伽 / 助眠

音乐退到几乎不存在，只剩空间。

```
meditation calm ambient
yoga peaceful flute
sleep deep drone
healing soundscape
```

- **drone**（持续音）和 **soundscape** 无节拍无旋律，最不打扰
- 助眠向看时长：10 分钟以上的才实用，曲库筛选器按时长拉

### 20. 恐怖 / 案件解说 / 灵异

吓人很容易，克制才高级。

```
dark horror tension
creepy music box
true crime suspense
horror drone atmosphere
```

- **music box**（八音盒）是恐怖反差神器，童声旋律配暗画面头皮发麻
- 案件解说用 `investigation` `crime` + `pulse`，保持冷静叙述感，别一惊一乍

### 流派词（回报率最高的一类标签）

场景词是"我猜你要干嘛"，流派词是"这就是这个声音"——心里已有目标听感时，直接搜流派 + 情绪，命中率最高：

| 流派词 | 听感 | 典型场景 |
|---|---|---|
| lofi hip hop | 磁噪、松弛、微丧 | 学习陪伴、教程、直播垫乐 |
| synthwave / retrowave | 80s 霓虹复古未来 | 科技、夜驾、复古内容 |
| phonk | 暗、漂移感、牛铃 | FPV、汽车、硬核卡点 |
| future bass | 明亮电子流行 | 产品发布、年轻向内容 |
| house / deep house | 四四拍律动、时髦 | 时尚、派对、高级感 |
| drum and bass | 快速碎拍 | 运动、高能剪辑 |
| trap | 重 808、暗、拽 | 潮流、运动、电竞 |
| dubstep | 重型贝斯爆发 | 卡点、预告片 |
| nu jazz / jazz hop | 爵士采样 + 节拍 | 探店、都市夜景 |
| bossa nova | 慵懒南美 | 美食、咖啡、烘焙 |
| swing / big band | 老派爵士大乐队 | 喜剧、复古、花絮 |
| neo-classical | 现代古典钢琴弦乐 | 情感、艺术片、婚礼 |
| post-rock | 后摇，安静堆到爆发 | 励志、纪录片高潮 |
| cinematic / film score | 电影配乐 | 预告、叙事、史诗 |
| ambient / drone | 无节拍氛围 | 冥想、铺底、科幻 |
| chiptune / 8-bit | 红白机音色 | 游戏、像素、复古 |
| funk / disco | 复古律动 | 花絮、时尚、喜剧 |
| gospel / choir | 圣咏人声 | 庄严、升华、结尾 |
| folk / americana | 木吉他草根感 | 旅行、户外、乡村 |
| reggaeton / latin | 拉丁律动 | 派对、海滩、舞蹈 |

### 能量 / 节奏词

`slow` · `mellow` · `laid back` · `mid-tempo` · `groovy` · `bouncy`（弹跳感）· `driving` · `pulsing`（脉冲）· `energetic` · `intense` · `aggressive` · `hard-hitting` · `hypnotic`（催眠感）· `building`（渐强）· `rising`（爬升）

### 功能结构词

| 词 | 意思 |
|---|---|
| underscore | 垫在说话底下的配乐（采访/纪录片必备） |
| bed | 同上，"音乐床"，播客圈用词 |
| instrumental / no vocals | 纯音乐无歌词——要铺底先把人声排掉 |
| loop | 可无缝循环的段落 |
| sting / stinger | 几秒钟的转场重音 |
| riser / build up | 情绪爬升段，转场和揭晓前用 |
| intro / opener | 开场曲 |
| outro / ending | 收尾曲 |
| jingle | 短促洗脑的品牌旋律 |
| 30 seconds / 60 seconds | 广告剪辑短版（曲库常给同一曲的多时长版本） |
| no drums / light mix | 同一曲的减法分轨版本，垫说话更干净 |
| no copyright / royalty free | 免版权（搜索时一般不用加，站内默认都是） |

## 三、避坑黑名单

这些词看着对，搜出来全是错的：

| 别搜 | 为什么 | 改搜 |
|---|---|---|
| `background music` | 太宽泛，出来全是口水电子乐 | 场景词 + 情绪词组合 |
| `interview` | 出来的是播客片头 jingle | `documentary underscore` |
| `BGM` | 日文圈词汇，欧美曲库没这个标签 | 任意场景词 |
| `trending` / `viral` | 追的是流量不是质感，出来全是短视频口水 | 流派词 + 情绪词 |
| `chinese` / `oriental`（想要国风时） | 免费曲库的国风标签量少，且多为刻板民乐小调，国潮嘻哈/新中式基本没有 | 民乐需求换国内素材站；只要"东方氛围"可用 `asian ambient` 凑合 |
| 直接搜歌名 / 歌手名 | 免费曲库没有主流版权曲，出来的都是蹭名仿作 | 用流派 + 情绪找平替 |
| `sad emotional epic` 堆太多情绪 | 词越多命中越乱，2–3 个词最准 | 精简到 场景+情绪+质感 各一个 |
| 中文关键词 | 免费曲库中文标签几乎为零 | 全英文 |

## 四、平台技巧

以 Pixabay 为主（国内可直连），通用于多数曲库：

1. **翻作者主页**：找到一首对味的，点进作者页——同一作者的制作水准和审美是稳定的，大概率有整柜同款
2. **标签反查**：好曲子的详情页会列全部标签，把它的标签拿来当搜索词，等于"以曲搜曲"
3. **善用筛选器**：搜索结果左侧可按时长、流派、情绪过滤；铺底选 2 分钟以上，短视频卡点选 1 分钟内
4. **看清 AI generated 标签**：曲库里大量曲子已是 AI 批量生成（会标注），质量参差，试听时留意结构是否单调
5. **铺底试听 30 秒法**：拖到中段听 10 秒 → 想象人声压上去打不打架 → 再快速拖两次听有没有突然的动态爆发。三关都过才收
6. **商用注意**：Pixabay Content License 可免费商用无需署名，但注意个别曲子标注 Content ID Registered——发 YouTube 可能触发版权匹配申诉流程，国内平台无碍
7. **一曲多版本**：不少曲子附 loop 版、30s 版、no drums 版，详情页或作者页里找——铺底卡时长时比硬剪干净得多
